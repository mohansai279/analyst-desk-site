The problem

Illustrative example; the numbers below are made up for the picture.

A normal AI writes
Revenue grew to $412.7 billion in 2024, driven by cloud.

Sounds right. The number may be invented or from the wrong year, and you can't tell.

Analyst Desk writes
Revenue grew to [REVENUE_2024] in 2024.
→ code fills $350.0 billion from the filed data
→ code checks it again ✓ verified

The AI never types a number. Code fetches it and checks it.

What happens to a bad request

"Should I buy this stock?"

Stopped at the input guard. We write research, not investment advice.

Hidden instruction inside a document

Retrieved text is treated as data. Injection phrases are scrubbed and the writer has no power to act on them.
