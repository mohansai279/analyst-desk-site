Security and memory

Sandbox: no network, no shell, no file access, empty environment (a real hole was found by our own test and fixed). Memory: four whitelisted style preferences, a private watchlist the model never sees, export and forget endpoints. Lessons from Reflexion are human-approved and frozen before the held-out run.

Limits, stated plainly
